# Physical Design Flow Analytics Dashboard

An interactive dashboard for analyzing and comparing ASIC physical-design runs using OpenROAD Flow Scripts.

## Project Objectives

- Track the RTL-to-GDSII physical-design flow.
- Collect area, timing, and power metrics where available.
- Compare physical-design runs with different configurations.
- Visualize PPA trade-offs using an interactive dashboard.

## Technology Stack

- OpenROAD Flow Scripts
- Docker
- Python
- Pandas
- Streamlit
- Plotly

## Project Status

Initial project setup and environment verification.

## Purpose

This project is developed for educational purposes and to demonstrate
ASIC physical-design flow analysis and data visualization skills.
